## 📖 About Us



We are a **free and open research project** exploring AI behavior, robustness, and safety. Our mission is to study how language models respond to diverse prompts, identify weaknesses, and promote responsible AI development.



We focus on:

- 🔍 Ethical red-teaming

- 🧪 Safety and robustness testing

- 📊 Transparent documentation

- 🤝 Community learning

## 🚀 How to Use



1. Navigate to the folder for your preferred language.

2. Choose the test case or evaluation prompt you want to use.



### 📥 Option A: Download



3. Download the file.

4. Place it in your project folder (or directly in `.gemini/config`).

5. Ask your agent to follow it as an example (e.g., “Act like example.md”).

6. Observe and document the model’s response for research purposes.



### 🔗 Option B: Use RAW URL



3. Click the **RAW** button on the file in GitHub.

4. Copy the URL.

5. Ask your agent to follow it (e.g., “Act like https://raw.githubusercontent.com/dilka32/...”).

6. Observe and document the model’s response.
